# Bài tập 40 — Mini game hứng táo

Project HTML, CSS và JavaScript thuần của **Võ Văn Quốc Bảo**, MSSV **231a290036**. Trang chủ có thông tin cá nhân và liên kết đến kết quả Bài 38, Bài 39 cùng mini game Bài 40.

## Mở project

Mở `index.html` bằng trình duyệt. Chọn **Bài tập 38**, **Bài tập 39** hoặc **Chơi mini game** trên trang chủ.

## Cấu trúc

- `index.html`, `style.css`, `main.js`: trang chủ cá nhân và menu.
- `assets/profile.jpg`: ảnh chân dung.
- `assets/bai-38-ket-qua.jpg`, `bai-38/`: ảnh và trang kết quả Bài 38.
- `bai-39/`: trang và toàn bộ source/assets Bài 39 được đóng gói để project chạy độc lập.
- `bai-40/index.html`, `bai-40/style.css`, `bai-40/game.js`: mini game hứng táo.
- `netlify.toml`: cấu hình thư mục publish tĩnh.
